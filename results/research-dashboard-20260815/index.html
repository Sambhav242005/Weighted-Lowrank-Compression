Activation-Weighted Low-Rank Compression

Can we compress transformer weights by preserving the directions the model actually uses, rather than treating every direction equally?

GitHub · Reader guide · Paper draft

The idea in 30 seconds

You don't need any background in linear algebra to understand the core insight.

A large language model stores its knowledge in massive weight matrices — grids of numbers with millions of entries. To compress the model, we need to replace these matrices with simpler approximations.

The standard approach (SVD) asks: "Which directions in this matrix carry the most mathematical energy?" It then keeps those directions and throws the rest away.

But here's the problem: the model doesn't use all directions equally. Some directions receive a flood of activation traffic every time the model runs. Others are barely touched. SVD doesn't know the difference — it spends its limited compression budget on directions that look big on paper but don't matter to the model's actual computation.

Our method asks a different question: "Which directions does the model actually use?" It then spends the compression budget on those directions specifically.

An analogy.

Imagine compressing a road network by preserving the roads with the most asphalt. You'd end up preserving some wide abandoned highways while destroying busy city streets. A better approach: preserve the roads with the most traffic. That's what activation-weighted compression does — it preserves the computational pathways the model actually travels.

Why standard compression fails

The "drift wall" at 3× compression was thought to be a fundamental limit. We show it's an artifact of the wrong objective.

When you compress a transformer's weight matrix using standard truncated SVD, something strange happens: even though each individual layer's error looks small, the full model's performance collapses. On GPT-2 Small, plain SVD at 3× compression raises perplexity by 21%. On Gemma-3-1B, it raises it by 72% — making the model nearly useless.

This failure has been attributed to two competing explanations:

Hypothesis 1: Drift accumulation

Approximation errors compound through the residual stream. Later layers receive inputs they were never trained on, so even a good per-layer fit doesn't guarantee a good network.

Hypothesis 2: Wrong norm

SVD minimizes error in weight space (Frobenius norm), but what matters is error under the activation distribution. SVD wastes rank on directions the model never excites.

Our finding:

The answer is overwhelmingly hypothesis 2. A closed-form fit that minimizes activation-space error recovers a full compression tier that plain SVD destroys. The "drift wall" is largely an artifact of the approximation method, not a fundamental limit.

SVD vs. our method

Two ways to compress the same matrix — different questions, different results.

Standard approach

Truncated SVD

  • Goal: Preserve maximum matrix energy
  • Question: "What is mathematically largest?"
  • Strength: Simple, established, efficient
  • Problem: Does not account for the model's activation distribution — spends rank on directions the model never uses
Our method

Activation-Weighted Fitting

  • Goal: Preserve behavior under representative activations
  • Question: "What does the model actually use?"
  • Strength: Compression objective follows the activation distribution
  • Tradeoff: Requires calibration data and additional computation during compression

The method

A closed-form solution — no gradient steps, per-matrix solve in seconds.

For a linear layer y = Wx, we capture calibration activations using a forward hook, then solve a simple optimization problem: minimize the activation-space error with a weight-space anchor to prevent divergence in unobserved directions.

Mathematical formulation

We seek a rank-r approximation Ŵ minimizing:

L(Ŵ) = (1/n) Σᵢ ‖(W − Ŵ)xᵢ‖² + β ‖Ŵ − W‖²_F

The first term is the activation-space error (what the network actually sees). The second is a weight-space anchor that prevents the fit from diverging in directions the calibration data never excites.

Let G = XXᵀ (activation Gram matrix) and C = (Y−b)Xᵀ + βnW (cross-moment). The unconstrained minimizer is:

M* = C (G + βnI)⁻¹

We then truncate M* to rank r in the G-weighted norm — the norm in which the original objective measures error. This is the exact rank-r minimizer given the full-rank optimum.

Algorithm overview

For each target module:

  1. Capture input activations X and outputs Y over calibration chunks (forward hooks)
  2. Subtract bias from Y if present
  3. Compute G = XXᵀ + βnI and C = YXᵀ + βnW
  4. Solve M* = CG⁻¹ (eigenspace solve with ridge regularization)
  5. Truncate to rank r in the G-weighted norm
  6. Write back the compressed factors

One hyperparameter: β (anchor strength). Optimal in [0.1, 0.3]; all results use β = 0.1.

Why the anchor matters

Without the anchor (β = 0), the problem is ill-posed in directions the calibration data never excites. The fit can produce arbitrarily large weights in those directions without any penalty, leading to divergence. The anchor ensures the compressed model stays close to the original in regions where we have no activation evidence.

Main result

Activation-weighted fitting defeats plain SVD by 5–7× in perplexity delta across three architectures and scales.

One sentence summary:

At the same compression budget, our method keeps models almost as smart as the original, while plain SVD makes them 4–16× worse.

What was compared?

Same model, same target matrices (attention output projections), same rank (one-sided 3× compression), same evaluation protocol (WikiText-2 test split). The only difference: SVD optimizes in weight space; our method optimizes in activation space.

Compression as denoising — can compression improve the model?

The Gemma-3-1B result is remarkable: the compressed model scores below the teacher's perplexity (−4.45% on 50 texts, −7.34% on 200 texts) with no fine-tuning. Logit-space analysis shows the student is not a copy — it has higher output entropy (2.19 → 2.47) and lower NLL, suggesting it's less overconfident and better calibrated.

Interpretation: directions of W that are never excited by natural text carry no signal but contribute weight-space capacity for spurious logits. Activation-weighted truncation removes them, flattening spurious peaks and moving mass onto correct tokens — denoising.

This claim rests on one architecture and one family. Three-seed replication and a second architecture are needed before claiming it broadly.

Factor quantization — int8 is lossless

On Qwen2.5-7B (rank 1194), quantizing the compressed factors to int8 is effectively lossless (+3.80% vs +3.86% for fp16), achieving 3.0× per-matrix storage reduction. int4 quantization costs an additional +4.4pp but remains within the quality gate.

What we can claim

Being precise about what the evidence supports, what's suggestive, and what remains open.

Supported by current evidence

Supported
  • Activation-weighted fitting outperforms plain SVD at the same rank budget on attention output projections across three architectures (GPT-2, Gemma-3, Qwen2.5).
  • The improvement factor is 5–7× in perplexity delta at 3× compression.
  • Int8 factor quantization is effectively lossless for the fitted subspace.
  • The "drift wall" at 3× compression is largely an artifact of the approximation norm, not a fundamental limit of scale.

Suggestive, needs additional validation

Suggestive
  • Compression can act as denoising (Gemma-3-1B beats the teacher). Requires multi-seed replication and a second architecture.
  • The hybrid low-rank + quantized residual design outperforms pure int4 on o_proj. Requires MLP-family evaluation where the payoff should concentrate.

Open — do not currently claim

Open
  • Algorithmic novelty over ASVD or EoRA — head-to-head comparison not yet run.
  • Whole-model compression — only attention output projections are demonstrated at 3×.
  • Deployment readiness — warmed-up latency, peak memory, and fused kernel behavior are unmeasured.
  • Downstream task performance — only perplexity has been evaluated.

What this paper does not claim

  • This work does not claim that low-rank compression universally beats quantization for storage. Quantization dominates pure storage; our value is quality-at-rank and the denoising effect.
  • This work does not claim that every transformer matrix is equally compressible. Only attention output projections are viable at 3×; MLP families break even with weighted fitting.
  • This work does not claim that activation weighting solves all compression problems. It is one technique with specific scope and tradeoffs.
  • This work does not claim deployment readiness. The compressed representation changes the compute graph; latency and memory implications are uncharacterized.
  • This work does not claim that the denoising effect is general. It has been observed on one architecture and requires multi-seed replication.

Limitations

Where this result stops being supported.

Scope of compression

Only attention output projections are demonstrated at 3×. MLP matrices — which contain 80% of parameters — break even with weighted fitting at this ratio. Whole-model compression requires budget reallocation across families, which we have not shown.

Statistical robustness

Most results are single calibration/fit runs. A ±1pp robustness test on disjoint calibration data shows stability, but multi-seed statistics are not yet available.

Evaluation scope

Evaluation is limited to perplexity on WikiText-2 (50–200 texts). No downstream-task evaluation, no pre-registered drift metric alongside PPL.

Latency and memory

Factored form changes the compute graph. Warmed-up latency and peak memory are unmeasured. Without a fused low-rank kernel, the storage win does not automatically become a speed win.

What did not work

Negative results are still results. They tell us where the method's boundaries are.

Direct pruning

Deleting 50% of weights (even using activation-aware selection) raised GPT-2 perplexity from 36 to 79 — still 2× worse than the original. At 90% pruning, perplexity exceeds 15,000. This suggests that pruning and low-rank compression are fundamentally different operations — pruning removes structure entirely, while low-rank compression redistributes it.

Student-input refitting

Trying to anticipate drift by fitting against the compressed model's own activations (rather than the original model's) consistently lost ~1pp across all settings. Anticipating drift is not the lever; fixing the norm is.

MLP compression at 3×

Weighted fitting on MLP matrices (c_fc, c_proj) produced 76–2149% PPL increases at 3× ratio. MLP families do not have enough redundancy at this compression level, even with activation-aware fitting.

Reference neurons

Using reference neurons to encode weight matrices (another compression approach) was consistently less efficient than matched SVD at every rank level tested. This confirmed SVD as the right baseline for our comparisons.

Related work

How this positions against existing methods.

Activation-aware quantization (GPTQ, AWQ)

What they solve: Post-training quantization — reducing the bit-width of weight entries.

What they optimize: Weight-space rounding error under the second-order (Hessian/activation Gram) statistic of calibration inputs.

How our method differs: We operate on the low-rank structure rather than quantization grids. Our objective is the low-rank analogue of their principle: preserve what activations actually use.

What remains uncertain: The interaction between our low-rank branch and quantization-aware baselines at matched budgets.

ASVD — Activation-aware SVD (Yuan et al., 2023)

What it solves: Reparameterizes weights by activation statistics before SVD, handling outlier channels.

What it optimizes: Activation-aware low-rank approximation for LLM compression.

How our method differs: Our closed-form anchored fit with weighted truncation is an independent derivation in the same family. The beats-the-teacher denoising effect has not been reported for ASVD.

What remains uncertain: Head-to-head comparison at matched budget and protocol is the sharpest novelty test and remains open.

EoRA — Eigenspace Low-Rank Compensation (Liu et al., 2024)

What it solves: Adds a low-rank residual path to compensate compression error.

What it optimizes: The compensation rank approximates compression error in the eigenspace of input activations.

How our method differs: EoRA adds a compensation path on top of a base compression; we replace the base compression itself. The two could potentially be combined.

What remains uncertain: Whether our method, EoRA, or a combination performs best at matched budgets.

QEP — Quantization Error Propagation (Arai & Ichikawa, 2025)

What it solves: Error accumulation across layers in quantized models — directly our drift problem, for quantization.

What it optimizes: Sequential layer-wise fitting against drifted inputs rather than teacher inputs.

How our method differs: QEP addresses cross-layer error propagation for quantization; we address the per-layer approximation norm for low-rank compression. The two problems are related but distinct.

What remains uncertain: Whether QEP-style cross-layer compensation would further improve low-rank compression.

SVDQuant — Low-rank + quantization hybrid (Li et al., 2024)

What it solves: Absorbs outliers into a low-rank branch, allowing aggressive quantization of the residual.

What it optimizes: Combined low-rank + int4 representation for diffusion models.

How our method differs: We show the low-rank branch itself survives int8 losslessly, reinforcing the hybrid design space. Our weighted-fit branch outperforms an SVD branch at matched storage.

What remains uncertain: Full hybrid evaluation on MLP families where the payoff should concentrate.

Glossary

Low-rank
A matrix represented using fewer underlying dimensions. Instead of storing every entry, you store two smaller matrices whose product approximates the original.
SVD
A standard mathematical method (Singular Value Decomposition) for finding the most important directions in a matrix. It's the default tool for low-rank approximation.
Activation
The signal produced inside a neural network when an input passes through a layer. Activations tell you which parts of the network are "firing" for a given input.
Calibration data
Representative inputs used to observe the model's activation patterns before compression. The method needs to "see" what the model does in order to know what to preserve.
Rank
The number of independent directions retained by the compressed representation. Higher rank = more faithful to the original but less compression.
Perplexity (PPL)
A language-model metric measuring how well the model predicts text. Lower is better. A PPL of 36 is good; a PPL of 15,000 means the model is essentially random.
Activation-weighted
A compression objective influenced by the directions emphasized by actual model activations, rather than by mathematical magnitude alone.
Gram matrix
A matrix summarizing which directions appear frequently in the calibration activations. It defines the geometry in which the compression error is measured.
